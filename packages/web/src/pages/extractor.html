Text Extractor

Pull emails, URLs, numbers and hashtags out of messy text, such as a web page copied into a document or a list of mixed contacts.

Result

How to use Text Extractor

  1. Paste text from a web page, document or list.
  2. Choose what to extract: emails, URLs, numbers or hashtags.
  3. Copy the results, with duplicates removed if you want.

How do I pull email addresses out of text?

Paste the text, keep Emails ticked, and copy the list from the result box.
