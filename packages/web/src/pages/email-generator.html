Email Generator

Make a list of random test email addresses, from 1 to 50,000. Use them for test accounts, sample data or seeding a database. The default domain is example.com, which is reserved for testing, so the addresses don't reach real people.

Emails

How to use Email Generator

  1. Enter how many addresses you need, from 1 to 50,000.
  2. Keep the example.com domain for testing, or enter your own domain.
  3. Copy the list, or download it as CSV or XLS for a spreadsheet.

Are these real email addresses?

They are random test addresses on example.com, a domain reserved for testing. They are not checked against real mailboxes.

Can I open the XLS file in Excel?

Yes. The file is an Excel-compatible spreadsheet with the addresses in one column named email.
