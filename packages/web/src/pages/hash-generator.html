Hash Generator

Type or paste text to get its hash. The hash is computed in your browser, so the text is never sent anywhere.

Hash

How to use Hash Generator

  1. Type or paste your text.
  2. Choose SHA-1, SHA-256, SHA-384 or SHA-512.
  3. Copy the hash.

Is my text sent to a server?

No. The hash is computed in your browser with the built-in Web Crypto API.

Which hash should I use?

SHA-256 is a good default for checksums. SHA-1 is older and no longer secure against deliberate attacks.
