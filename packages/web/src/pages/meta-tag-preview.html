How to use Meta Tag Preview

  1. Enter the page title and description.
  2. Check the search and share previews and any warnings.
  3. Copy the tags into your page head.

How long should a title be?

Search results usually show about 60 characters, so keep titles near that.

How long should a description be?

About 120 to 160 characters. Longer text is cut off in search results.
