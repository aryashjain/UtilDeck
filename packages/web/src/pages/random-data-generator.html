Random Data Generator

Make random table data: up to 10 columns and 1,000,000 rows, as CSV or JSON. Pick a column type for each column. Preview the first rows, then download the full file.

Preview (first 20 rows)

How to use Random Data Generator

  1. Choose the number of columns, up to 10.
  2. Pick a type for each column and the number of rows, up to 1,000,000.
  3. Preview, then download the CSV or JSON file.

How big a file can I make?

Up to 1,000,000 rows and 10 columns. Large files take longer, and copy works up to 10,000 rows.

Is this data real?

No. Names, emails and phone numbers are made up. Phones use the 555 range, and emails use example.com.
