YAML and JSON Converter

Convert YAML to JSON or JSON to YAML. Errors point to the line that needs fixing. Runs in your browser.

How to use YAML and JSON Converter

  1. Paste YAML and choose YAML to JSON, or paste JSON and choose JSON to YAML.
  2. Fix any error at the line shown, and copy the result.

Why does YAML fail on indentation?

YAML uses spaces to show structure, so a line indented wrongly changes or breaks the meaning.

Is my YAML sent anywhere?

No. It is parsed in your browser.
