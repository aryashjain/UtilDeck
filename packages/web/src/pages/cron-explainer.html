    How to use Cron Explainer

    1. Type a five-field cron expression.
    2. Read the plain English version and the next five run times.
    3. Use the examples to start from a common schedule.

    What do the five cron fields mean?

    Minute, hour, day of month, month and day of week, in that order.

    Which time zone are the run times in?

    Your device's local time. Servers often use UTC, so check the zone your scheduler uses.
