SVG Optimiser

Remove the extra data that design tools leave in SVG files, such as comments, metadata and hidden groups. The picture looks the same, and the file is smaller. Runs in your browser.

Preview

How to use SVG Optimiser

  1. Paste SVG code or drop an SVG file.
  2. Read how much smaller the optimised version is.
  3. Check the preview, then download the .svg.

Will the picture change?

The shapes and colours stay the same. Only unneeded data such as comments and metadata is removed.

Is my SVG uploaded?

No. The optimisation runs in your browser.
