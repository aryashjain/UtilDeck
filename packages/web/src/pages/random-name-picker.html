Random Name Picker

Paste one name per line, choose how many winners you want, and pick. Every name has the same chance.

How to use Random Name Picker

  1. Paste one name per line.
  2. Choose how many winners you need.
  3. Press Pick. Use Pick again to draw a new set.

Is the pick fair?

Yes. Names are shuffled with the browser's secure random source, so every name has the same chance.

Are the names stored?

No. The list stays in your browser and is not sent anywhere.
