XML Validator and Formatter

Check whether XML is well formed, and see the exact error if it is not. Valid XML can be formatted with indentation. Runs in your browser.

How to use XML Validator

  1. Paste your XML.
  2. Press Validate to check it, or Validate and format to see it indented.

What does Not valid XML mean?

The XML breaks a rule, such as an unclosed tag. The message shows the first problem found.

Is my XML uploaded?

No. Validation runs in your browser.
