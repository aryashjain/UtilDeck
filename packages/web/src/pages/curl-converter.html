cURL to Code

Paste a curl command to get the same request as JavaScript fetch or Python requests code. Nothing is sent; the code is only written out.

JavaScript (fetch)

Python (requests)

How to use cURL to Code

  1. Paste a curl command.
  2. Copy the JavaScript or Python version.

Does this send the request?

No. It only writes code. Use the API tester to send a request.

Which curl options are supported?

Method, headers, data, basic authentication and the URL. Other options are ignored.
