How to use URL Parser and Builder

  1. Paste a link and press Parse.
  2. Edit the host, path, parameters or fragment. The built link updates as you type.
  3. Copy the rebuilt link.

Why is my link rejected?

A link needs a scheme such as https://, and a host name.

Does this send my link anywhere?

No. Parsing and building happen in your browser.
