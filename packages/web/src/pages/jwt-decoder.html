JWT Decoder

Paste a JSON Web Token to read its header and payload. Decoding happens in your browser and nothing is sent anywhere. This tool does not verify the signature, so do not trust a token only because it decodes.

How to use JWT Decoder

  1. Paste a JSON Web Token.
  2. Read the header, payload, issued and expiry times.

Does this verify the token?

No. It only decodes it. A token can decode fine and still be forged, so the signature must be checked on the server.

Is my token sent anywhere?

No. Decoding runs in your browser.
