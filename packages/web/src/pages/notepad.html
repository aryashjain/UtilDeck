How to use Notepad

  1. Type or paste your text. It saves automatically in this browser.
  2. Use the Stats tab for words, characters and reading time.
  3. Use the Share tab to create a link. Anyone with the link can read the note for 3 hours.

Is my note saved if I close the page?

Yes. Notes are saved in your browser, so they stay on this device until you clear them.

Can I protect a shared note with a password?

Yes. Tick Password protect before creating the link. Readers must enter the password to see the note.
