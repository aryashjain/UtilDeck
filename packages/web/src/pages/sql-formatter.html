SQL Formatter

Make SQL readable: keywords in capitals, one clause per line, and indented joins and conditions. Runs in your browser; your queries are not sent anywhere.

How to use SQL Formatter

  1. Paste your SQL query.
  2. Read the formatted version, with keywords in capitals and one clause per line.
  3. Copy or download the result.

Does this run my query?

No. It only rearranges the text. Nothing is run or sent anywhere.

Which SQL dialects work?

Standard SQL keywords work across common databases. Dialect-specific syntax is kept as written.
