Regex Tester

Type a pattern and some text. Every match is listed with its position and any capture groups. Uses JavaScript regular expression syntax.

How to use Regex Tester

  1. Type a pattern without the slashes.
  2. Add flags such as g for all matches or i to ignore case.
  3. Read each match with its position and capture groups.

What do the flags mean?

g finds all matches, i ignores case, m makes ^ and $ match each line, and s lets dot match new lines.

Does this use the same regex rules as JavaScript?

Yes. It uses JavaScript regular expression syntax.
