Color Converter and Contrast Checker

Pick a color or type a HEX value. Check the text and background pair against WCAG contrast levels.

How to use Color Converter

  1. Pick a color with the picker or type a HEX value.
  2. Read the RGB and HSL values.
  3. Set a text and background color to check the contrast ratio.

What contrast ratio is good enough for text?

WCAG AA asks for 4.5 to 1 for normal text and 3 to 1 for large text. AAA asks for 7 to 1.

Which color formats are supported?

HEX (3 or 6 digits), RGB and HSL.
