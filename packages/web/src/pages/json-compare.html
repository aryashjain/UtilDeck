How to use JSON Compare

      
  1. Paste the original JSON in the left box and the changed JSON in the right box.
  2. Read the list of values that differ, with the exact path of each one.
  3. Use the changed lines below to see the difference in the formatted JSON.

      
How do I compare two JSON files?
Open both files, copy their contents, and paste one into each box. The differences appear as you type.
Does the order of keys matter?
No. Keys are compared by name, and the changed-lines view sorts keys so reordering alone is not reported.
