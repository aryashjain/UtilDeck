How to use JSON Formatter

  1. Paste your JSON into the input box.
  2. Choose Format to indent it, or Minify to make it one line.
  3. Read the status line. It shows whether the JSON is valid and where it breaks if not.

Why is my JSON invalid?

The most common causes are trailing commas, single quotes instead of double quotes, and missing quotes around keys.

Is my JSON uploaded anywhere?

No. Formatting and validation run in your browser.
