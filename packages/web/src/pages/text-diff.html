How to use Text Diff

  1. Paste the original text in the first box.
  2. Paste the changed text in the second box.
  3. Review the highlighted differences to see what was added or removed.

How do I compare two versions of a document?

Copy the older version into the first box and the newer version into the second. Added and removed text is highlighted.
