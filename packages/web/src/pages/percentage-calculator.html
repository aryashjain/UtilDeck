Percentage Calculator

Three common percentage questions. Type in any row and read the answer beside it.

How to use Percentage Calculator

  1. Pick the question: percent of a number, part of a whole, or percent change.
  2. Type the numbers, and the answer updates as you type.

How do I calculate a percentage increase?

Use percent change: (new - old) / old x 100.

What if the starting value is zero?

Percent change is undefined when the starting value is zero, so the tool shows an error.
