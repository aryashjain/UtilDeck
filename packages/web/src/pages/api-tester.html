How to use API Tester

      
  1. Choose a method and enter the URL.
  2. Add headers and a body if needed, then send the request.
  3. Read the status, time, headers and response.

      
Why does a request fail?
Some servers block requests from other websites, which the browser reports as a failed request.
Are my requests sent through a server?
No. The request goes straight from your browser to the URL you enter.
