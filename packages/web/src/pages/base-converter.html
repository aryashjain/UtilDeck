Base Converter

Convert a number between binary, octal, decimal and hex. Updates as you type, and handles very large numbers exactly.

BaseValue

How to use Base Converter

  1. Type a number and choose its base.
  2. Read it in binary, octal, decimal and hex, and copy any value.

Does it handle very large numbers?

Yes. It uses exact integer arithmetic, so large numbers stay correct.

Can I type a prefix such as 0x?

Yes. The prefixes 0x, 0b and 0o are accepted.
