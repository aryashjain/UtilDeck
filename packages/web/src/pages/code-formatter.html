Code Formatter and Minifier

Format HTML, CSS or JavaScript so it is easy to read, or minify it to make it smaller. Runs in your browser; nothing is sent anywhere.

How to use Code Formatter and Minifier

  1. Paste HTML, CSS or JavaScript.
  2. Choose Format to make it readable, or Minify to make it smaller.
  3. Copy the output or download it.

Does this run my code?

No. It only reformats or shrinks the text. Nothing is executed or sent anywhere.

Why minify code?

Smaller files load faster. Keep the readable version for development and minify for production.
