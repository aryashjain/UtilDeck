Compress PDF

Make a PDF smaller by drawing each page as an image at the quality you choose. Pages become pictures, so their text cannot be selected or searched afterwards.

How to use Compress PDF

  1. Choose a PDF.
  2. Set the image quality and page sharpness.
  3. Download the compressed PDF and check the size.

Why can I not select the text afterwards?

Compression draws each page as a picture, so the text becomes part of the image.

What if the file gets bigger?

Lower the quality or the sharpness. Scanned or image-heavy PDFs shrink the most.
