CSV and JSON Converter

Turn a spreadsheet export (CSV) into a JSON array, or a JSON array into CSV. Handles quotes and commas inside cells. Runs in your browser.

How to use CSV and JSON Converter

  1. Paste CSV with a header row, or a JSON array of objects.
  2. Choose the direction and copy or download the result.

How are numbers and true or false handled?

Numbers and true or false values become JSON numbers and booleans when converting CSV to JSON.

Can cells contain commas?

Yes. Quote the cell, as in "Pune, India", and the comma stays inside it.
