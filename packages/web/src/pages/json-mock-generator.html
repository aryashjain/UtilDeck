JSON Mock Generator

Make a sample JSON document for testing an API, a form or a database. Choose how many keys each object has and how deeply objects are nested. Values are random strings, numbers, booleans and nulls.

JSON

How to use JSON Mock Generator

  1. Set how many keys each object should have.
  2. Set how deeply objects should be nested.
  3. Copy the JSON or download it as mock.json.

What is mock JSON?

Sample JSON with made-up values, used to test an API, form or database before real data exists.

Why is there a limit?

Each extra level multiplies the number of objects. The limit keeps the page responsive, and the message tells you how many objects a request would create.
