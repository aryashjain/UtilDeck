QR Code Generator

Type a link or text to make a QR code. It is generated in your browser, so nothing you type is sent to a server.

How to use QR Code Generator

  1. Type a link or text.
  2. Choose a size.
  3. Download the QR code as a PNG.

Is my text sent to a server?

No. The QR code is drawn in your browser by a library bundled with the site.

How much can a QR code hold?

Up to 1,000 characters in this tool, which is plenty for a link.
